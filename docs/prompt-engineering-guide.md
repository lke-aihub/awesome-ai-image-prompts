# 提示词工程指南

## 1. 先写“交付物”，再写风格

弱提示词常从“高级、电影感、8K”开始，却没有说明要交付什么。更稳定的顺序是：

```text
生成什么 → 给谁用 → 解决什么问题 → 画面必须包含什么 → 怎样才算成功
```

例如，不要只写“做一张高级咖啡海报”，而应先写“生成一张4:5新品主图，商品占55%，顶部留标题区，标签必须清楚”。

## 2. 九段式结构

| 段落 | 要回答的问题 | 示例 |
|---|---|---|
| 任务 | 输出类型是什么？ | 电商主图、三视图、信息图 |
| 主体 | 谁/什么是主角？ | 一瓶香水，严格保持瓶型 |
| 动作 | 主体在做什么？ | 悬浮、行走、回头、拆解 |
| 构图 | 主体放哪里？ | 右侧三分之一，占画面55% |
| 场景 | 前中后景有什么？ | 洞石台面、渐变墙、虚化枝叶 |
| 风格 | 用何种视觉语言？ | 编辑摄影、铜版画、功能主义UI |
| 光色 | 光从哪里来？颜色做什么？ | 左后柔光，橙色只标重点 |
| 文字 | 哪些文字必须准确？ | 标题、日期、参数逐条写死 |
| 约束 | 什么绝不能发生？ | 不改Logo、不加人物、不拼版 |

## 3. 变量不要含糊

把“好看一点”“科技感”改成可观察的条件：

- “高级” → 大面积负空间、限制四色、材质真实、标题层级明确。
- “科技感” → 深色中性背景、细网格、冷色轮廓光、信息路径发光但不过量。
- “电影感” → 明确焦段、机位、景别、光比、色温和画面叙事时刻。
- “国风” → 指定时代、材料、纹样来源、线条和色彩，排除龙凤祥云的泛化堆砌。
- “真实” → 指定镜头、接触阴影、材质反射、皮肤纹理、环境光与轻微缺陷。

## 4. 中文文字的稳定方法

1. 只保留必要文字，标题优先控制在14字内。
2. 在提示词里逐字写出最终文案，不让模型自由扩写。
3. 明确层级和位置，例如“标题位于左上，副标题两行以内”。
4. 数据、日期、单位和品牌名列成独立清单。
5. 长正文建议后期排版；先让模型生成无字底图，再用设计工具加字。

## 5. 参考图编辑的保真优先级

多图编辑时，不要只说“参考这几张图”。给每张图分工，并声明优先级：

```text
A图只提供人物身份；B图只提供服装；C图只提供场景。
保真优先级：身份 > 服装结构 > 姿态 > 构图 > 风格。
```

明确“不可变项”比反复写“保持一致”更有效：脸型、发际线、Logo位置、瓶盖结构、纹样坐标、相机角度等都应点名。

## 6. 信息图先做信息架构

推荐四层：

```text
一句结论 → 一眼看懂的主视觉 → 支撑结论的证据 → 可执行的总结
```

图表类型应匹配关系：

- 时间变化：折线、时间轴。
- 类别比较：条形图、点图。
- 构成关系：堆叠条形、有限数量的环形图。
- 空间分布：地图、路径、热区。
- 过程机制：流程、剖面、因果箭头。
- 层级系统：树、同心圆、分层轴测。

不要为了“丰富”同时放折线、饼图、雷达图、卡片和地图；每一种图形都应承担一个问题。

## 7. 一次只迭代一个变量

推荐顺序：

1. 构图与主体比例。
2. 身份、产品或角色一致性。
3. 光线和色彩。
4. 材质与细节。
5. 文字和边角清理。

如果一次同时改变镜头、风格、服装、背景和色板，就很难判断结果为什么变好或变坏。

## 8. 常见失败与修正

| 失败 | 原因 | 修正写法 |
|---|---|---|
| 海报像拼贴板 | 没限定单幅成品 | “只生成一张海报，不要moodboard或多方案” |
| 商品结构漂移 | 只说“参考商品” | 列出瓶型、瓶盖、标签、Logo、角度等不可变项 |
| 角色每格换脸 | 同时改变太多条件 | 固定身份、服装、镜头，每格只改变表情或动作 |
| 信息图乱码 | 文案太长且未写死 | 只保留短标题、数据和编号；正文后期排版 |
| 室内像豪宅 | 没有真实尺寸 | 写明面积、家具尺度、通行宽度和镜头焦段 |
| “国风”俗套 | 文化定义过宽 | 指定地域、时代、材料与纹样来源，并列出禁止符号 |
| 光影像贴图 | 合成时未统一光 | 指定主光方向、色温、接触阴影和环境反射 |

## 9. 模型适配提示

- **自然语言理解强的模型**：可直接使用完整段落与“不可变项”清单。
- **偏关键词式模型**：保留主体、构图、媒介、光线、色板和禁止项，将解释性句子压缩。
- **支持参考图权重的模型**：身份或商品参考图权重高于风格参考图；不要让风格图覆盖主体结构。
- **局部编辑模型**：掩膜只覆盖需要修改的区域，并在提示词中重复“其他区域保持不变”。

## 10. 发布前检查清单

- [ ] 主体、用途和画幅是否明确？
- [ ] 构图是否给出位置、比例和视觉动线？
- [ ] 文字、数字、单位是否逐字写死？
- [ ] 参考图各自的角色与保真优先级是否明确？
- [ ] 风格是否用可观察属性描述，而不只是空泛形容词？
- [ ] 禁止项是否针对这类任务最常见的失败？
- [ ] 是否核验事实、授权、商标、肖像与商业使用边界？
