# 🧩 可变量化提示词模板

填写方括号变量即可使用。每类“快速版”适合单次生成，“进阶版”适合高要求交付与 Agent 调用。

## 1. 信息图与知识视觉

**快速模板**

```text
生成一张[比例]的“[主题]”信息图。核心读者：[读者]；阅读目标：[目标]。
结构：[主视觉] + [模块1] + [模块2] + [模块3] + [总结区]。
用[流程/地图/时间线/对比/分层剖面]组织信息，标题必须写“[标题]”，关键数字使用[数据]。
视觉：[风格]，[背景色]，[主色/强调色]，信息密度[低/中/高]但层级清楚。
不要编造数据，不要长段乱码，不要卡片过多。高清，[比例]。
```

**进阶模板**

```text
你是信息设计师。把以下资料转化为一张可独立阅读的信息图：[粘贴资料]。
先识别一个核心结论，再建立“标题层—概览层—证据层—行动层”四级结构。
主视觉使用[视觉隐喻]；证据区只选择最适合数据关系的图形：[图表类型]。
准确文字清单：[逐条列出必须出现的文字与数字]。
版式：[栅格]；视觉动线：[方向]；配色角色：背景[色]、事实[色]、重点[色]、风险[色]。
图标保持同一线宽和视角，单位、图例、数据口径一致。
禁止：虚构事实、装饰性假图表、相互矛盾的数字、过小正文、无关插画。
输出：[比例/尺寸]，适合[屏幕/印刷]。
```

## 2. 海报与字体

**快速模板**

```text
为[活动/作品]设计单幅海报。主标题“[准确标题]”，副标题“[副标题]”，日期地点“[信息]”。
主视觉：[人物/物体/视觉隐喻]，构图：[中央/对角/三分/巨型字体]。
风格：[编辑设计/电影/实验字体/复古印刷]，限制色板：[4至6色]。
标题是第一视觉层级且必须可读，画面预留[区域]。
不要moodboard，不要多方案，不要额外文案，不要拼错文字。[比例]。
```

**进阶模板**

```text
为标题“[标题]”生成一张完成度极高的概念海报，只生成一张成品。
概念冲突：[A与B的关系]；把它转化为一个视觉隐喻：[隐喻]。
标题与图像必须发生[遮挡/穿插/托举/切割/负空间]关系，而非并排摆放。
字形属性：字重[ ]、字宽[ ]、节奏[ ]、边缘材质[ ]、可读性优先级[ ]。
构图：主视觉占[ ]%，负空间[ ]%，信息放在[位置]。
准确文字仅包含：[逐条列出]。
媒介：[丝网印刷/摄影/纸艺/3D/拼贴]；色板：[ ]；颗粒和材质：[ ]。
禁止：通用字效、随机图标、样机、多稿拼版、虚构Logo、额外小字。
```

## 通用负面约束块

```text
禁止项：不要额外人物或物体；不要重复主体；不要改变身份、产品结构或品牌文字；
不要乱码、拼写错误、无意义小字；不要错误手指、肢体、透视、反射和阴影；
不要过度磨皮、过度锐化、塑料材质、廉价光效、过饱和、元素堆砌；
不要moodboard、多方案拼版、样机展示或解释文字，除非任务明确要求。
```
