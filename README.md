# Awesome AI Image Prompts

一套持续更新的中文 AI 图像提示词库。

这里收录的不是零散关键词，而是可以直接使用、修改和复用的完整提示词。每个案例都配有对应例图，方便快速判断构图、风格和最终效果是否符合自己的需求。

目前已经整理：

- 48 个完整提示词案例
- 48 张对应效果图
- 12 个常用创作分类
- 24 套可复用提示词模板

## 为什么整理这个仓库

使用 AI 生成图片时，真正影响结果的往往不是关键词数量，而是有没有把需求说明白。

例如：

- 画面主体是什么
- 主体处于什么环境
- 镜头从哪个角度拍摄
- 光线、色彩和材质如何表现
- 图片中需要出现哪些文字
- 哪些内容不能改变或不能出现
- 最终图片用于海报、商品页还是社交媒体

这个仓库希望把这些要求整理成清晰、稳定、可以直接修改的提示词案例，让创作过程少一点反复试错。

## 使用方法

找到与目标最接近的案例，复制提示词，然后替换其中的主体、场景、颜色、文字和尺寸。

建议一次只调整一个主要变量。

例如，第一次先确认构图，第二次调整颜色，第三次再处理文字和细节。这样更容易判断是哪一项修改影响了最终结果。

## 关于例图

仓库中的案例图片与提示词一一对应，文件编号采用：

```text
case01.png
case02.png
case03.png
...
case48.png
```

涉及换背景、局部修改、照片修复和多图合成的案例，会明确标注为“合成演示”，避免与真实人物、商品或历史资料混淆。

## 原创说明

仓库中的提示词、案例说明和配套示例以原创整理、独立制作为基本原则。

我们不会直接搬运其他项目的文案、案例描述或品牌信息。确有正式合作、授权引用或共同创作的内容时，会在对应位置单独说明。

如果没有特别标注，则代表该内容属于本项目独立整理的公开版本。

## 参与完善

如果你发现提示词存在以下问题，欢迎提交 Issue：

- 图片文字不够准确
- 构图描述容易产生歧义
- 案例图片与提示词不一致
- 缺少某个常用创作方向
- 同一角色或商品的一致性不足

也欢迎提交新的原创案例。新增内容需要同时提供完整提示词、使用场景、输出比例和对应例图。
